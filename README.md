# Multimodal AI & Interactive Applications

A Generative AI web application that allows users to interact with AI using **text, images, PDF documents, and audio**.

## Features

- Text-based AI conversations
- Image analysis
- PDF analysis
- Audio analysis
- File upload
- Chat history
- ChatGPT-inspired UI

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **AI Model:** Google Gemini
- **API:** Gemini API

## Project Structure


app.py
model.py
index.html
style.css
script.js
requirements.txt


## How to Run

### 1. Install dependencies

pip install -r requirements.txt


### 2. Add API key

Create a `.env` file:

env
GEMINI_API_KEY=your_api_key


### 3. Run

bash
python app.py


Open:

text
http://127.0.0.1:8000
